# UI critique gallery

Every view from the UI critique scoreboards, round by round, from the first review to the last. [ui-critique-summary.md](ui-critique-summary.md) has the score trajectory and what each round changed. Click an image to open it at full size.

The images are assets of the [`ui-critique-shots-2026-11-06` release](https://github.com/ballest-editor/ballest-editor/releases/tag/ui-critique-shots-2026-11-06), at most 1200 px wide. Each file is `r<round>-<shot>.webp`, and the shot names are the ones the round docs cite.

## How to read it

- Rounds 7 and 8 shipped together and share a scoreboard column, so R7/8 shows the round 8 shots.
- A `–` score means the round did not score that view. An empty cell means no shot exists for it.
- A light cell is the `-light` twin where one exists. Before the twins start, some cells use a `38-light-*` shot of the same view, and each section lists its names.
- The Theme scores are the scoreboards' T column on the Theme row.
